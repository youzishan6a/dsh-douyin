# 抖音收藏分类表

`summarize` 与 `unfavorite` 的 `--types` 参数接受三类写法：

1. 分类 id，如 `food`；
2. 中文名，如 `美食`；
3. 任意关键词，如 `露营`、`面试`、`评测`。

多个值用英文或中文逗号分隔：`--types 美食,旅行` 或 `--types food,travel`。

## 内置分类

| id | 中文名 | 典型命中词（节选） |
| --- | --- | --- |

匹配范围是标题、作者、标签。标题命中权重 2，作者/标签权重 1，取得分最高的一类；并列时按上表顺序取靠前者。

## 自定义类型

传入非内置词时按关键词处理，命中标题/作者/标签即算匹配。例如：

```bash
node scripts/douyin.mjs summarize --types 露营,徒步
node scripts/douyin.mjs summarize --types 面试
```

关键词匹配不区分大小写，按子串匹配，因此「评测」也能命中「手机评测：这次值得买」。

## 排除条件的解析规则

`--exclude` 接收一句自然语言，脚本会：

1. 去掉开头语气词：`不要`、`别`、`除了`、`排除`、`去掉`、`不看`、`不想看`、`不需要`；
2. 去掉紧随其后的 `总结`、`归纳`、`整理`；
3. 按 `，、；。空格` 和 `和 / 与 / 跟 / 以及 / 还有` 拆分；
4. 去掉每段结尾的 `类型`、`类`、`的视频`、`视频`、`内容`；
5. 去重后逐个做子串排除。

示例：

| 输入 | 实际关键词 |
| --- | --- |
| `不要总结带货和直播切片` | `带货`、`直播切片` |
| `除了 游戏、明星八卦` | `游戏`、`明星八卦` |
| `不要带货` | `带货` |
| `和平精英` | `和平精英`（整体保留，不会被「和」拆开） |

排除命中标题、作者或标签中的任意一处，该条就不会进入结果。

## 筛选叠加顺序

`summarize`：先按类型筛选 → 再按排除词过滤 → 最后按 `--since-days` 过滤 → 按发布时间倒序 → 分组。

`unfavorite`：先按类型 → 再按排除词 → 再按时间基准分组 → 取最老的 N 条。
